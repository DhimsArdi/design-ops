# Design Portfolio Planner

**Status:** Planning / Pre-development

## Purpose

Internal design portfolio and manpower visibility tool. It will help the design team map projects, timelines, team structure, squads, designers, project ownership, business stakeholders, and cross-squad designer assignments.

## Development status

Development has not started yet. This repository currently contains planning documentation and Claude working structure only — no application code, framework, or dependencies have been installed.

See [`/docs/PRD.MD`](docs/PRD.MD) for the current product requirements.
